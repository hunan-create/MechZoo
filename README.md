# MechZoo — What Can a Single Table Tell About Its Missingness Mechanism?

Artifact package for the paper *"What Can a Single Table Tell About Its Missingness
Mechanism? Testable Limits, a Diagnostic, and a Benchmark"* (anonymous submission).

The paper settles what a **single** incomplete table can and cannot reveal about its
missingness mechanism (MCAR / MAR / MNAR), and ships three artifacts:

1. **Theory** — a testable hierarchy: pattern homogeneity is the only non-trivial
   restriction the observed law places on the mechanism; above it, MAR and genuinely-MNAR
   generators are observationally equivalent (dual rationalization), the pooled
   observed-residual law under self-selection is exactly extended skew-normal with an
   attenuation law, pooled residual-shape tests cannot be consistent, and selection
   strength is link-relative.
2. **MechZoo** — a mechanism-labelled benchmark: 6 base families + 3 held-out families,
   real tables with injected mechanisms, and a joint-shift cell (real tables × held-out
   families); 2,472 evaluation tables across 5 cells, all generated from fixed seeds.
3. **MissDx** — a zero-shot diagnostic (per-column statistics → set-attention encoder →
   calibrated posterior over the hierarchy) that beats a pattern-targeted moment test on
   MCAR detection by +4.6–5.5 pp AUROC, is calibrated in-distribution, and *declares*
   where its calibration ends.

Every number, table, and figure in the paper is produced by a script in this repository;
the exact result files behind each table are shipped in `results/`.

## Repository layout

```
code/            experiment & figure scripts (run from this directory)
checkpoints/     MissDx weights (e1_model_iter2.pt = main runs, e1_model_retrain.pt =
                 second training run for the 0.4-pp training-variance bound,
                 e1_model.pt / e1_model_pcc.pt = earlier runs kept for lineage)
data_cache/      (inside code/) offline cache of the 9 public real tables
results/         all result files referenced by the paper (JSON + per-table score NPZ)
figures/         the paper's 8 figures; regenerated by the make_fig*/fig_* scripts
paper/           camera-ready LaTeX source (main_icde_press.tex + IEEEtran.cls + figs)
```

## Quick start

```bash
pip install -r requirements.txt
cd code
```

Main results on CPU (~1 min each; no GPU needed — evaluation only):

```bash
python levels_report.py 0 ""        # Table 4 rows: in-dist / base-fresh / held-out / joint-shift (draw 1)
python levels_report.py 1 "_s1"     # draw 2
python levels_report.py 2 "_s2"     # draw 3  (Table 4 = mean over the three draws)
python audit_cells.py --device cpu  # §5.2 Little comparison: AUROC 0.948–0.954 vs 0.899–0.903
                                    #   + paired-bootstrap 95% CI + per-cell ECE + selective risk
python real_per_source.py           # Table 4 real-inj row (pooled L2 = .690 / .721, exact)
python dk_baseline.py               # Heckit two-step column of Table 4
python little_standard.py           # Little (1988) standard omnibus test (≈ chance, §5.2)
python heckit_control_v2.py         # §5.6 Gaussian control: size/power vs τ_f², t3 arm
python tabpfn_baseline.py           # TabPFN zero-shot baseline (needs tabpfn; GPU recommended)
python e3b.py                       # §5.4 preregistered routing experiment (Table 6)
python theory_align.py              # §5.3 ESN attenuation 16-cell grid + λ-sweep + link table
python esn_extended.py              # §5.3 extended α₀≠0 six-cell grid (rate 0.25)
python invariant_strength.py        # §5.8 quantile-contrast estimator ρ (link-invariant C)
python feature_ablation.py          # §5.5 per-feature ablation of the value-aware probe
python calibration_table.py         # Table 7 per-cell fine/coarse ECE
python wide_runtime.py              # wide-table transfer (d ≤ 100) + runtime curve
python entropy_boot.py              # entropy separation + bootstrap CI (§4 claim ii)
python make_figs.py                 # fig_esn.pdf, fig_lambda.pdf
python make_fig_calib.py            # fig_calib.pdf (reliability + per-family entropy)
python fig_levels.py && python fig_per_family.py && python fig_calib_ece.py && python fig_per_source.py
```

Retraining MissDx from scratch (optional, ~190 s on one consumer GPU):

```bash
python e1_amortized.py --h 128 --pool_per_class 4000 --epochs 12 --bs 32 \
       --out e1_retrain_results.json --ckpt e1_model_retrain.pt
```

Scripts write their outputs to the current directory (`code/`); the shipped copies of the
paper's runs live in `../results/`. All evaluation cells are generated from fixed seeds
(999 / 777 / 778 / 500+k / 900+k), so every cell regenerates without network access — the
real tables are cached in `code/data_cache/`.

## Notes on the real tables

The nine sources are breast-cancer, diabetes, page-blocks (OpenML 30), MagicTelescope
(OpenML 1120), balancing-scale, qsar-biodeg, wine-quality-white, synthetic-control, and
ILPD; the exact arrays used for every shipped number are cached in
`code/data_cache/` (`real_tables.npz` = first 4 sources, `real_tables9.npz` = all 9), so
nothing requires network access. If you delete the cache, `realdata9.py` will try to
re-fetch from OpenML; two of the sources (balancing-scale, synthetic-control) may then be
substituted by same-pipeline public tables (ecoli, climate-model-simulation-crashes) —
keep the shipped cache to reproduce the paper's numbers.

## Known reproduction gaps (disclosed)

The paper's exact per-number provenance is complete except for the following, disclosed
for transparency:

1. **Table 8 per-source breakdown**: the pooled L2 values (.690/.721 — i.e. the Table 4
   real-inj row) regenerate exactly with `real_per_source.py`; the per-source split was
   produced by a batch script whose per-source evaluation detail was not archived, so
   regenerated per-source values differ from the shipped `expanded_real_results.json`
   (which remains the paper's record). Same for the L1 column of the real-inj row
   (.730/.870/.870, a three-draw mean from the same unarchived pass).
2. **Table 5**: values are the confusion matrix of `e1_iter2_results.json`
   (recall .707/.560/.727/.840/.987/.767 — exact); the "largest sink" column is read off
   the same matrix.
3. **Regeneration noise**: `invariant_strength`, `esn_extended`, and
   `calibration_table` regenerate with fresh RNG streams, so values land at the paper's
   scale (invariant ρ: .873/.928 vs paper .87/.918; ESN extended |dev| ≤ .015 vs
   paper ≤ .033; calibration monotone .03–.04 → ~.3, joint-shift coarse .305 exact)
   but not digit-for-digit. `feature_ablation` regenerates full macro-F1 = .724 vs the
   shipped .763 with partially overlapping top features (indices 27 and 14 in both
   top-5) — the original pass's probe variant was not archived. The shipped JSONs are
   the paper's runs. Everything else regenerates exactly: `audit_cells.py` on CPU
   reproduces the shipped `audit_cells.json` AUROC block digit-for-digit in ~30 s
   (model .9541 / little .8994 / diff 5.48 pp / CI [3.58, 7.44]), and
   `real_per_source.py` reproduces the Table 4 real-inj pooled L2 row exactly
   (.690 / .721).
